# 用户使用指南

1. **怎么开始？** 调用 `$inner-knights-roundtable`，然后输入一个具体困惑。也可以直接说“为这个选择开一场内在骑士圆桌会议”。
2. **一次说一个事。** 如果同时纠结“要不要辞职”和“要不要分手”，分开开两场会。
3. **表面问题不是纠结核心。** “要不要绝交／辞职／分手”会一直作为会议目标保留，但主持人会先逐层看清：发生了什么、哪里受伤、需要什么、赋予了什么意义、哪两个价值在拉扯，以及每条路怕失去什么。
4. **一轮只剥一层。** 主持人会根据当前层只召唤最合适的一位骑士。骑士先分析和质疑，再留下一个容易接下去、能向内推进的话头；七位骑士不需要全部出场。
5. **诚实面对身体。** 只有当身体感受与主要矛盾相关时，感知者才会出现。此时不要美化或分析，直接回答“胃紧了”“胸口热了”之类的原始感受。
6. **72小时倒计时。** 纠结核心看清并形成决心书后，在72小时内迈出第一小步；若仍缺一个关键事实，也可以先签《72小时验证契约》。
7. **可以指定或更换角色吗？** 可以。用户可要求某位骑士回应，或把某位骑士换成更适合自己的角色；变更仅对当前会议生效，除非明确要求更新技能本身。

推荐开场提示：

> 使用 `$inner-knights-roundtable` 帮我主持一场内在骑士圆桌会议。表面决定是：……先不要急着给结论，请逐层剥开我为什么纠结，直到能准确说出“我既……又……”的核心冲突；每轮只召唤最合适的一位骑士，并留下一个能自然向内推进的接话入口。
