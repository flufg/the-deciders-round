# 用户使用指南

1. **怎么开始？** 在 Codex 当前聊天调用 `$inner-knights-roundtable` 并描述你的话题或迷茫，或说“为这个选择开一场内在骑士圆桌会议”。无需启动本地服务器或配置独立 API。主持人按需调用骑士子 Agent；环境不支持时会说明并改为单 Agent 多视角。已有背景直接进入讨论，无需重述。多 Agent 可能增加等待时间和用量，本地网页原型仅用于另外选择的实验。
2. **怎样讨论？** 主持人组织不同视角互相回应，让具体疑惑逐渐显现；已有明确问题时可以直接深入。不急着替你选定方向，也不把所有问题都抛给你。无需凑齐七席，也不限定每轮只能一席；事实、感受和需要可以连起来讨论。
3. **会主动推进吗？** 会。主持人主动组织探索，沿讨论中浮现的线索和你的回应深入；需要时自然提问，条件成熟时主动总结。你可以纠正或改变方向，不需要持续提供新话题。骑士也会检验不同解释；理解更清楚本身就是进展，不必每轮走向决定。
4. **会强迫二选一吗？** 不会。圆桌不默认要求作决定。理清认识、发现新问题或保留分歧都可以是成果；你希望权衡选择时，再讨论方案和行动。
5. **怎样结束？** 主持人先总结原始疑惑、已澄清认识、当前答案或条件性理解和剩余未知，再确认你的疑惑是否解决。确认后展示完整纪要，未解决就继续；也可以随时暂停并保留未完成的停点。
6. **必须签决心书吗？** 不必。主持人总结并完成解惑确认后即可自然结束；愿意行动时明确下一步。喜欢仪式感时可使用决心书或验证契约；72小时是小行动的参考窗口，按现实条件安排，不要求复述誓词。
7. **怎样使用画像？** 本机的人物素描帮助骑士借助你的优势、补充当前讨论遗漏的视角。当前表达优先，个人画像不会上传Git；你可查看、更正、删除或停止维护，也可要求本场不用画像。主持人仅向骑士传递必要摘要；文件本地保存不等于离线推理，使用的内容仍会进入 Codex 模型上下文。更新技能会保留它，普通讨论不会为了补画像变成采访。
8. **可以改角色吗？** 可以。角色调整默认只对当前会议生效，除非明确要求更新技能。
9. **怎样复盘？** 带着行动结果回来，围绕新观察和改变的假设继续，无需重开全场。
10. **需要不断提供证据吗？** 不需要。圆桌先按你的陈述讨论并保留不确定性；当你的体验或表达含义影响理解时，会自然澄清；尚未核实的事实可以保留并作条件分析，不逐项索证。不知道可以直接说，不会被反复索证或据此怀疑动机。
11. **会突然变成另一项任务吗？** 铁砧信使可在会中查阅相关外部信息，带入社会、行业、制度与真实案例，并说明来源和局限。练习、独立调研报告、创作或操作等另有交付目标的任务，默认记入会后事项；只有你明确要求或接受切换才开展。
12. **纪要怎样记录？** 在会话中持续整理议题、重要认识、倾向、未决问题与会后事项，结束后统一呈现；可随时查看草稿。建议和已接受的行动会区分，不自动更新人物画像。需要本地文件时可以要求保存，个人纪要不会上传Git。

推荐开场：

> 使用 `$inner-knights-roundtable` 帮我讨论：……请组织多视角探索，让我在讨论中理清思绪，再沿浮现的线索深入；结束前由主持人总结，并确认我的原始疑惑是否解决。
