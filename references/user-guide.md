# 用户使用指南

1. **怎么开始？** 调用 `$inner-knights-roundtable`，然后输入一个具体困惑。也可以直接说“为这个选择开一场内在骑士圆桌会议”。
2. **一次说一个事。** 如果同时纠结“要不要辞职”和“要不要分手”，分开开两场会。
3. **诚实面对身体。** 感知者询问身体反应时，不美化、不分析，直接回答“胃紧了”“胸口热了”之类的原始感受。
4. **72小时倒计时。** 决心书生成后，在72小时内迈出第一小步；过期未执行则重新审视决定。
5. **可以改角色吗？** 可以。用户可要求把某位骑士换成更适合自己的角色。角色一经变更，仅对当前会议生效，除非用户明确要求更新技能本身。
