# 用户使用指南

1. **怎么开始？** 调用 `$inner-knights-roundtable`，然后输入一个具体困惑。也可以直接说“为这个选择开一场内在骑士圆桌会议”。
2. **一次说一个事。** 如果同时纠结“要不要辞职”和“要不要分手”，分开开两场会。
3. **表面问题不一定是纠结核心。** 主持人会保留“要不要绝交／辞职／分手”这个目标，再看清事实、受伤、需要、解释、价值、现实约束和害怕失去的东西。
4. **不强造两难。** 核心可能是“我既……又……”，也可能是“我想……但被某个事实、代价或恐惧卡住”。若只缺关键事实，就先验证，不做心理化解释。
5. **一轮只剥一层。** 主持人每轮只召唤最合适的一位骑士。骑士会阐述自己的判断；当你的话中存在可检验的推论时，他也会提出真实摩擦，再留下容易回应的接话入口。
6. **诚实面对身体。** 只有身体感受与主要矛盾相关时，感知者才会出现。直接报告“胃紧了”“胸口热了”等原始感受，不必替它下结论。
7. **72小时倒计时。** 形成决心书后，在72小时内迈出第一小步；若仍缺一个关键事实，可以先签《72小时验证契约》。
8. **可以指定或更换角色吗？** 可以。角色变更默认只对当前会议生效，除非明确要求更新技能本身。

推荐开场提示：

> 使用 `$inner-knights-roundtable` 帮我主持一场内在骑士圆桌会议。表面决定是：……先不要急着给结论，请逐层剥开我真正卡在哪里。每轮只召唤最合适的一位骑士，让他从自己的角度分析；有值得质疑的推论时就提出摩擦，并留下一个让我容易继续说下去的接话入口。
