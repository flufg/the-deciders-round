# 用户使用指南

1. **怎么开始？** 调用 `$inner-knights-roundtable`，然后输入一个具体困惑。也可以直接说“为这个选择开一场内在骑士圆桌会议”。
2. **一次说一个事。** 如果同时纠结“要不要辞职”和“要不要分手”，分开开两场会。
3. **一轮只聊一个点。** 主持人会根据你最新的回答，只召唤当前最合适的一位骑士，问一个问题，然后等你回应；七位骑士不需要全部出场。
4. **诚实面对身体。** 只有当身体感受与主要矛盾相关时，感知者才会出现。此时不要美化或分析，直接回答“胃紧了”“胸口热了”之类的原始感受。
5. **72小时倒计时。** 决心书生成后，在72小时内迈出第一小步；若仍缺一个关键事实，也可以先签《72小时验证契约》。
6. **可以指定或更换角色吗？** 可以。用户可要求某位骑士回应，或把某位骑士换成更适合自己的角色；变更仅对当前会议生效，除非明确要求更新技能本身。

推荐开场提示：

> 使用 `$inner-knights-roundtable` 帮我主持一场内在骑士圆桌会议。我纠结的是：……请根据我的每次回答动态选择最合适的一位骑士，不要一次让所有角色发言。
