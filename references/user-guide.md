# 用户使用指南

1. **怎么开始？** 调用 `$inner-knights-roundtable` 并描述一个具体困惑，或说“为这个选择开一场内在骑士圆桌会议”。已有背景直接进入讨论，无需重述。
2. **怎样讨论？** 每轮聚焦一个主要推进点，默认由最适合的一位骑士分析。事实、感受和需要可以连起来讨论，不必逐层填问卷。
3. **会主动推进吗？** 会。你负责选择，主持人负责判断接下来最值得讨论什么，并实际展开分析；缺少关键信息时主动提问，条件成熟时主动总结。你可以纠正或改变方向，不需要持续提供新话题。角色发现实际漏洞才质疑，不为推进强造问题。
4. **会强迫二选一吗？** 不会。圆桌保留你的原始目标，允许调整边界、尝试小动作或先验证关键事实，不强造两难。
5. **怎样结束？** 主持人先总结原始疑惑、核心卡点、当前答案和剩余未知，再确认你的疑惑是否解决。你可以自然回答，未解决就继续；也可以随时暂停。
6. **必须签决心书吗？** 不必。主持人总结并完成解惑确认后即可自然结束；愿意行动时明确下一步。喜欢仪式感时可使用决心书或验证契约；72小时是小行动的参考窗口，按现实条件安排，不要求复述誓词。
7. **怎样使用画像？** 本机的人物素描帮助骑士借助你的优势、补充当前讨论遗漏的视角。当前表达优先，个人画像不会上传Git；你可查看、更正、删除或停止维护。更新技能会保留它，普通讨论不会为了补画像变成采访。
8. **可以改角色吗？** 可以。角色调整默认只对当前会议生效，除非明确要求更新技能。
9. **怎样复盘？** 带着行动结果回来，围绕新观察和改变的假设继续，无需重开全场。
10. **需要不断提供证据吗？** 不需要。圆桌先按你的陈述讨论并保留不确定性；只有缺失信息会实质改变当前判断、又无法通过条件分析继续时，才要求补充。不知道可以直接说，不会被反复索证或据此怀疑动机。

推荐开场：

> 使用 `$inner-knights-roundtable` 帮我讨论：……请根据当前矛盾选择角色，主动推进，有依据时提出不同视角；结束前由主持人总结，并确认我的原始疑惑是否解决。
